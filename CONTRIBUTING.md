# Contributing

Changes to the codec contract require a rationale, compatibility analysis, updated conformance vectors, and tests. Keep the implementation narrowly scoped to deterministic serialization and decoding.

Before submitting a change:

1. Read `AGENTS.md`, `docs/CODEC-CONTRACT.md`, and the AIX Core contract.
2. Add positive and negative tests for the changed behavior.
3. Run the local unit-test command from the README.
4. Document any interoperability limitation or breaking behavior.
5. Do not include credentials, private data, or unpublished operational material.

Use pull requests for reviewed changes. Do not claim production or standards conformance without reproducible evidence.
